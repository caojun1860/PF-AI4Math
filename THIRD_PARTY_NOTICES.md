# Third-party skills and components

This repository vendors project-local Agent skills so research runs remain reproducible. Exact repositories, paths and pinned commits are recorded in `config/skills-lock.json`.

- K-Dense scientific-agent-skills: SymPy, literature review, citation management, peer review, scientific critical thinking, scientific writing, LiteParse and MarkItDown skill material. Individual skill metadata records MIT, Apache-2.0 or linked upstream terms.
- cameronfreer/lean4-skills: Lean 4 skill material, MIT.
- bytedance/deer-flow: academic paper review skill material; consult the pinned upstream repository for its license and notices.
- openags/paper-search-mcp: paper-search skill material; consult the pinned upstream repository for its license and notices.
- hueyexe/opencode-ensemble: Agent orchestration skill and plugin configuration, MIT.

The top-level project license has intentionally not been selected. Before making a public repository, choose a license for original project code and preserve every upstream notice required by the pinned sources.
